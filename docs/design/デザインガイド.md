## 1. デザインコンセプト

**「ダッシュボード(計器盤)」**をモチーフにしたテーマ。

- ヘッダは車の計器盤を思わせる**パネルネイビー**、主要アクション(給油を記録)は**メーターアンバー**(メーター照明・燃料計の警告灯の色)で、画面内で最も目立たせる
- 燃費などの数値は**メーター表示のように大きく・等幅数字**で見せる
- 背景は明るいライトグレー基調。**直射日光下(給油所)での視認性**を最優先し、淡い色のテキストを多用しない(コントラスト比 4.5:1 以上を原則とする)

### 設計原則(優先順)

1. **記録が最速**: 給油入力は必須2項目(ODO・給油量)+保存で完了(金額は任意)。前回値・今日・満タンONを初期値にし、判断と入力を減らす
2. **片手・親指操作**: 保存ボタン・大ボタン・FAB・タブバーはすべて画面下半分に配置。ヘッダ側には「戻る/キャンセル」など低頻度操作のみ置く
3. **誤記録の防止**: どの画面でも「いま選択中の車両」が見える。入力画面にも対象車両を表示する
4. **警告は出すが止めない**: バリデーションは原則「警告表示(保存可)」。入力の手を止めない(要件 6.1 準拠)

### 使い分けルール

- **アンバー = 「記録する」**: 給油記録CTA・保存ボタン・追加FABに限定。1画面に大きなアンバーは原則1つ
- **ブルー = 「移動・選択」**: リンク、二次ボタン、フィルタ・期間チップの選択状態
- 満タンバッジ=ブルー系 / 部分給油(計算待ち)=グレー系 / 警告=アンバー系(warn) / 削除=レッド

## 3. タイポグラフィ

フォント: システムフォント(追加読み込みなし。オフライン・表示速度優先)

```
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto,
             "Hiragino Sans", "Noto Sans JP", "Yu Gothic UI", sans-serif;
```

数値(燃費・金額・ODO)は必ず `font-variant-numeric: tabular-nums`(等幅数字)を指定し、桁が揃って読めるようにする。

| トークン | サイズ/行間 | ウェイト | 用途 |
|---|---|---|---|
| `display` | 44px / 1.1 | 700 | ホームの直近燃費(最大表示) |
| `num-lg` | 28px / 1.2 | 700 | 入力欄の数値、詳細画面の燃費 |
| `title` | 18px / 1.4 | 700 | 画面タイトル、カード見出し |
| `body` | 15px / 1.6 | 400 | 本文・リスト主文 |
| `sub` | 13px / 1.5 | 400 | 補助情報(単価・日付・前回値ヒント) |
| `caption` | 11px / 1.4 | 500 | バッジ・タブラベル・単位 |

### タッチターゲット

| 要素 | 高さ |
|---|---|
| 最小タップ領域 | **48px**(下回る場合は余白で拡張) |
| リスト行 | 56px以上 |
| 主要ボタン(保存・給油を記録) | **56px**、ホームのCTAは64px |

| タブバー | 56px + セーフエリア(`env(safe-area-inset-bottom)`) |

### 親指リーチ(想定幅375〜430px縦持ち)

- **下段(タブバー・保存バー・FAB)**: 毎回使う操作
- **中段**: 入力欄・リスト(スクロール操作)
- **上段(ヘッダ)**: 表示(車両名)・キャンセルなど低頻度操作のみ。上段に必須タップを置かない

## 5. 共通コンポーネント

### 5.1 アプリバー(ヘッダ)+ 車両チップ

- 高さ56px、`--c-panel` 背景・白文字。上端はセーフエリア対応
- **車両チップ**: **車両タイプアイコン(車/バイク。5.12参照)**+車両名+下向きシェブロン。**タップで車両切り替えシート(S-11)を開く**。タップ可能に見えるよう半透明白の角丸背景を敷く。アイコンは選択中の車両のタイプに追従して切り替わり、車とバイクがひと目で区別できる
- 一覧系画面(S-01/03/06/07)には車両チップを必ず表示。入力系(S-02/04/05)はヘッダは「✕(キャンセル)+タイトル」とし、対象車両はフォーム先頭行に表示(その場で変更可)
- 車両に依存しない画面(S-08 車両管理 / S-09 設定)はタイトルのみ

### 5.2 タブバー

- 4タブ: **ホーム / 給油(→S-03) / メンテ(→S-06) / 設定(→S-09)**。白背景+上罫線
- アクティブ: ネイビーのアイコン・ラベル+上辺にアンバーのインジケータバー(3px)
- 入力画面(S-02/04/05)ではタブバーを非表示(モーダル的に扱い、誤タップ防止)

### 5.3 ビッグナンバー(燃費表示)

- `display`(44px)+単位(`caption`、`--c-sub`)。「19.2 <small>km/L</small>」
- 直下に補助行(平均燃費・前回差分)。前回比は ▲良化=green / ▼悪化=danger の小バッジ

### 5.4 数値入力フィールド(NumField)

給油入力の中核コンポーネント。

- 構成: ラベル(左上・13px)/ 数値入力(28px・右寄せ)/ 単位サフィックス(km・L・円)
- **必須/任意の表記**: 必須はラベル横に赤の「*」、任意はグレー(`--c-sub`)の小さめテキスト「任意」をラベル横に付ける
- `inputmode="decimal"`(給油量)または `inputmode="numeric"`(ODO・金額)で**テンキーを起動**。`type="text"`+patternではなく `type="number"` 系を基本とする
- **前回値ヒント**: 欄の下に「前回: 34,512 km」等を13pxグレーで表示。ODOはプレースホルダにも前回値を出す
- 自動計算結果(単価)は欄の下に「単価 ≒ 160円/L(自動計算)」とライブ表示。**元値(金額)が未入力の間は計算結果を出さず**、案内文「単価は金額を入力すると自動計算されます(前回 ◯円/L)」を表示。一覧・詳細で値が無い場合は「—」表示
- 警告時: 欄の下に `--c-warn-bg` の角丸チップで警告文(保存はブロックしない)。エラー(必須未入力)は赤文字+保存ボタン無効

### 5.5 満タントグル(Switch)

- 52×32pxのスイッチ+ラベル「満タン」。**初期値ON**
- OFF時は補助文「燃費は次の満タン給油時にまとめて計算されます」を表示し、計算待ちになることを予告する

### 5.6 リスト行(給油履歴・メンテ履歴)

- 高さ64px前後、白背景、行間罫線。行全体がタップ領域(→詳細へ)。右端にシェブロン
- 給油行: 左=日付(2段: 月日+曜日)/ 中=給油量・金額・単価 / 右=**燃費バッジ**
  - 燃費確定: ネイビー地バッジ「19.2 km/L」
  - 計算待ち(部分給油): グレー地バッジ「計算待ち」
- メンテ行: 左=種別アイコン+種別名 / 中=日付・ODO・店舗 / 右=費用

### 5.7 FAB(追加ボタン)

- 56px円形・アンバー・「+」アイコン。右下(タブバーの上、`right:16px / bottom:タブバー+16px`)
- S-03(→給油入力)・S-06(→メンテ入力)に表示

### 5.8 ボトムシート(車両切り替え S-11)

- 画面下から出現、上辺角丸20px、グラバーバー付き。背後は半透明黒(タップで閉じる)
- 車両行(56px): **車両タイプアイコン(車/バイク)**+車両名+補足(メーカー等)、選択中はチェックマーク+ブルー文字
- 最下部に「+ 車両を追加」(→S-08)
- **ヘッダの車両名タップ(1)→車両タップ(2)の2タップで切り替え完了**し自動で閉じる。切替時はトーストで結果を通知

### 5.9 ボタン

| 種類 | 見た目 | 用途 |
|---|---|---|
| Primary(アンバー) | アンバー地+濃色文字、高さ56px、角丸20px | 保存、給油を記録 |
| Secondary(ブルー) | 白地+ブルー罫線・文字 | メンテを記録、CSV書き出し等 |
| Text | ブルー文字のみ | キャンセル、グラフを見る等 |
| Danger | 赤文字(白地)/確認ダイアログ内は赤地 | 削除 |

- 保存ボタンは**フォーム下部に固定(sticky)**し、スクロール位置に関わらず親指で押せる

### 5.10 チップ(フィルタ・期間切替)

- 高さ36px、角丸full。非選択=白地グレー罫線 / 選択=ネイビー地白文字
- S-06の種別フィルタ、S-07の期間切替(直近12回/半年/1年/全期間)に使用。横スクロール可

### 5.11 トースト / 確認ダイアログ

- トースト: 画面下部(タブバー上)に2秒表示。「保存しました(燃費 19.2 km/L)」のように**結果の数値を含めて**通知
- 削除は必ず確認ダイアログ(中央モーダル)。削除ボタンは赤、キャンセルを左・削除を右に配置

### 5.12 車両タイプアイコン(車/バイク)

- 車両タイプ(`car` / `motorcycle`)ごとに専用の**24pxストロークSVGアイコン**を用意する(絵文字は使わない。§7 アイコン方針に統一)
  - 車: ボディ+ホイール2輪の線画
  - バイク: 前後ホイール+フレーム・ハンドルの線画
- 表示箇所: ヘッダの車両チップ(5.1)/ 車両切り替えシートの車両行(5.8)/ S-08車両一覧の行頭 / 入力画面の「対象車両」行。**車両名が表示される場所には必ずタイプアイコンを添える**
- サイズ: チップ内20px / 対象車両行22px / リスト・シート行24px。色は文脈のテキスト色に従う(`currentColor`)

### 5.13 セグメントコントロール(車両タイプ選択)

- S-08 車両登録・編集フォームの「車両タイプ」に使用。**アイコン+ラベル付きの2択(車/バイク)を1タップで選択**
- 形状: 薄グレー(#E7ECF2)のトラック+選択中セグメントは白地・影付き・濃色文字(角丸8px、高さ44px)
- 選択変更時はメーカー候補(5.14)を即時切り替える

### 5.14 メーカー選択(プルダウン+手入力)

- S-08 車両登録・編集フォームのメーカー欄に使用。`<select>`(ネイティブピッカー)を基本とし、**車両タイプに応じて候補を切り替える**:
  - 車: トヨタ / ホンダ / 日産 / マツダ / スバル / 三菱 / スズキ / ダイハツ / レクサス / メルセデス・ベンツ / BMW / フォルクスワーゲン / アウディ / ボルボ
  - バイク: ホンダ / ヤマハ / スズキ / カワサキ / ハーレーダビッドソン / BMW / ドゥカティ / トライアンフ / KTM
- 先頭に「選択してください」(未選択・任意項目のため)、**末尾に「その他(手入力)」**を置き、選択するとメーカー名のテキスト入力欄を直下に表示する
- タイプ切り替えで候補が変わった場合、選択済みメーカーが新候補に無いときは未選択に戻す(誤った組み合わせを残さない)

## 6. バリデーション表示ポリシー

| 種類 | 表示 | 保存 |
|---|---|---|
| 必須未入力(ODO・給油量。金額は任意) | 保存ボタンを無効化(グレー)+ボタン下に「あと◯項目」 | 不可 |
| ODOが前回より小さい | 欄下に警告チップ「前回(34,512km)より小さい値です」 | **可**(要件6.1) |
| 給油量がタンク容量超過 | 欄下に警告チップ | 可 |
| 算出燃費が1〜60km/L範囲外 | 保存前に警告チップ「燃費が◯km/Lになります。入力をご確認ください」 | 可 |

## 7. モーション・その他

- 画面遷移: フェード+わずかな上方向スライド(150ms)。ボトムシートは下からスライド(200ms)。過剰なアニメーションは使わない
- ダークモード: MVPでは対応しない(屋外視認性優先のライト固定)。フェーズ2以降で検討
- アイコン: 24pxストロークアイコン(Feather系のシンプルな線画)をインラインSVGで使用。**絵文字はUIに使用しない**(OS間で見た目が変わり、計器盤テーマの統一感を損なうため)。車両タイプアイコン(車/バイク)も同方針のSVG線画で統一する(5.12)
