## 0. 共通仕様

### 0.1 画面構造

```
┌──────────────────────────┐
│ アプリバー(パネルネイビー)   │ ← 車両チップ or タイトル+戻る
│──────────────────────────│
│                          │
│  コンテンツ(スクロール)      │
│                          │
│  [保存バー(入力画面のみ)]    │ ← sticky。常に親指圏内
│──────────────────────────│
│ ホーム | 給油 | メンテ | 設定  │ ← タブバー(入力画面では非表示)
└──────────────────────────┘
```

- タブ対応: ホーム=S-01 / 給油=S-03(FABでS-02へ)/ メンテ=S-06(FABでS-05へ)/ 設定=S-09
- 入力・詳細画面(S-02/04/05)はタブバー非表示のモーダル扱い(誤タップ防止、キャンセルはヘッダ左の✕/戻る)
- 一覧・ホーム系画面(S-01/03/06/07)のヘッダには**車両チップ**(**車両タイプアイコン〔車/バイク〕**+選択中の車両名)を常時表示。タップでS-11を開く。アイコンは選択中の車両のタイプに追従する
- S-08(車両管理)・S-09(設定)は車両横断の画面のため車両チップなし(S-09には選択中車両名をテキスト表示)

### 0.2 バリデーション表示の共通ルール

| レベル | 対象 | 表示方法 | 保存 |
|---|---|---|---|
| エラー(必須) | 必須項目の未入力 | 保存ボタンを無効化+ボタン下に「あと◯項目(必須はODO・給油量のみ。金額は任意)」 | 不可 |
| 警告 | ODO逆行 / タンク容量超過 / 燃費1〜60km/L範囲外 | 該当欄の直下にアンバーの警告チップをライブ表示 | **可**(要件6.1準拠) |

- 警告はダイアログにしない(入力の手を止めない)。入力のたびに即時再評価する
- 保存成功はトーストで通知し、**結果の燃費値を含める**(例: 「保存しました(燃費 19.2 km/L)」)

### 0.3 数値入力の共通仕様

| 項目 | inputmode | 補助表示 |
|---|---|---|
| ODO(km) | `numeric` | プレースホルダ+欄下ヒントに前回値 |
| 給油量(L) | `decimal`(小数2桁) | — |
| 金額(円)※任意 | `numeric` | **金額入力時のみ**欄下に「単価 ≒ ◯円/L(自動計算)」をライブ表示。未入力時は案内文「単価は金額を入力すると自動計算されます(前回 ◯円/L)」 |
| 費用(円) | `numeric` | 0円可 |

- 任意の数値項目(金額・費用)は、ラベル横にグレーの小さめテキスト「任意」を付ける(必須は赤の「*」)

## S-01 ホーム(ダッシュボード)

| 項目 | 内容 |
|---|---|
| 目的 | 現状把握(直近燃費)と、給油入力への最短導線 |
| ヘッダ | 車両チップ(左)+今日の日付(右) |

**レイアウト(上→下)**
1. **ヒーローパネル**(ネイビー・下角丸): 直近燃費を44pxのビッグナンバーで表示。下段に「平均燃費 / 前回比(▲緑・▼赤)/ 今月の燃料費」
2. **CTA群**(画面中央=親指圏内):
   - 「給油を記録」: アンバーの特大ボタン(64px)→ S-02
   - 「メンテを記録」: ブルーの二次ボタン(56px)→ S-05
3. **燃費推移カード**: 直近12回のミニ折れ線(スパークライン)。カードタップ/「グラフを見る」→ S-07
4. **直近のメンテナンスカード**: 直近2〜3件(種別・日付・ODO・店舗・費用)。「すべて見る」/行タップ → S-06
5. (フェーズ2)リマインダー警告をヒーロー直下に挿入予定

**操作・遷移**: 車両チップ→S-11 / 給油を記録→S-02 / メンテを記録→S-05 / グラフ→S-07 / メンテ→S-06

**表示ルール**: 数値はすべて選択中の車両のもの。給油記録が無い場合、ビッグナンバーは「—」+「最初の給油を記録しましょう」を表示(初回はS-08の車両登録から開始)。**今月の燃料費は金額入力済みの給油記録のみを集計**する(金額なし記録は合計に含めない)

## S-02 給油入力【最重要画面】

| 項目 | 内容 |
|---|---|
| 目的 | 給油直後の最速入力。**目標30秒・アプリ起動から保存まで10タップ以内**(数値入力を除く) |
| ヘッダ | ✕(キャンセル→前画面)+タイトル「給油を記録」。タブバー非表示 |

**レイアウト(入力順=画面上→下。頻度の高い項目ほど上、任意項目は下)**

| # | 項目 | 初期値・入力支援 |
|---|---|---|
| 1 | 対象車両 | 選択中の車両。行タップでS-11を開きその場で変更可(誤記録防止) |
| 2 | 給油日 | **今日**(`type="date"`) |
| 3 | ODO(必須) | プレースホルダ+ヒントに**前回ODO**。`inputmode="numeric"` |
| 4 | 給油量(必須) | `inputmode="decimal"`。単位L表示 |
| 5 | 支払金額・総額(**任意**) | `inputmode="numeric"`。ラベル横にグレーの「任意」表示。**金額入力時のみ単価を欄下にライブ自動計算表示**、未入力時は案内文+前回単価を表示。単価側からの入力はMVPでは詳細画面に譲り、本画面は総額のみ |
| 6 | 満タントグル | **初期値ON**。OFF時は「燃費は次の満タン給油時にまとめて計算されます」を表示 |
| 7 | 燃費プレビュー | 満タンON+**ODO・給油量入力済**で「この区間の燃費 ◯km/L・走行◯km」を保存前に表示(燃費はODOと給油量のみで計算するため**金額なしでも表示される**) |
| 8 | 給油所名(任意) | **前回値を初期表示** |
| 9 | メモ(任意) | 空 |

**操作・遷移**
- 保存(sticky・アンバー56px)→ トースト「保存しました(燃費 19.2 km/L)」→ S-01へ戻る
- 部分給油の保存時はトースト「燃費は次の満タン給油で確定します」
- ✕ → 入力破棄して前画面へ(入力がある場合は破棄確認 ※実装時)

**タップ数の検証(標準フロー)**

| # | 操作 |
|---|---|
| 1 | (ホーム)「給油を記録」をタップ |
| 2 | ODO欄をタップ(テンキー入力) |
| 3 | 給油量欄をタップ(テンキー入力) |
| 4 | 金額欄をタップ(テンキー入力)※任意 |
| 5 | 「保存する」をタップ |

→ 金額まで入れて**5タップ**、**金額を入力しない場合は4タップ**(日付=今日、満タン=ON、給油所=前回値のためタップ不要)。要件の10タップ以内を満たす

**保存条件・バリデーション**
- **保存ボタンの活性条件: ODO・給油量の2項目が入力済み**(金額は不問)。揃うまで保存ボタン無効+「あと◯項目(必須はODO・給油量のみ。金額は任意)」表示
- ODO<前回ODO: ODO欄下に警告チップ(保存可)
- 給油量>タンク容量: 警告チップ(保存可)
- 算出燃費が1〜60km/L範囲外: 警告チップ(保存可)

**※データ項目への影響**: 金額の任意化は要件定義書(F-02・5.2 FuelRecord)に反映済み。`totalPrice` は null 許容(金額未入力時は `unitPrice` も null)

## S-03 給油履歴一覧

| 項目 | 内容 |
|---|---|
| 目的 | 給油と燃費の履歴確認(選択中の車両) |
| ヘッダ | 車両チップ+タイトル+「グラフ」テキストボタン(→S-07) |

**レイアウト**: 日付降順のリスト。行構成:

| 位置 | 内容 |
|---|---|
| 左 | 日付(月日+曜日の2段) |
| 中 | 給油量・金額(太字)/ 単価・満タン区分バッジ(満タン=青 / 部分給油=グレー) |
| 右 | **燃費バッジ**: 確定=ネイビー地「19.2 km/L」/ 部分給油=グレー地「計算待ち」 |

- **金額なし記録の表示**: 金額欄は「¥ —」、単価欄は「@— 円/L」と表示(燃費バッジはODO・給油量から通常どおり表示)
- リスト下に注記「『計算待ち』は次の満タン給油時にまとめて燃費が確定します。金額は任意入力のため、未入力の記録は金額・単価を『—』と表示します」
- 右下にFAB(+)

**操作・遷移**: 行タップ→S-04 / FAB→S-02 / 「グラフ」→S-07 / 車両チップ→S-11

## S-04 給油詳細・編集

| 項目 | 内容 |
|---|---|
| 目的 | 記録の確認・修正・削除 |
| ヘッダ | ←戻る(S-03)+タイトル。タブバー非表示 |

**レイアウト(上→下)**
1. **算出サマリカード**(緑背景): 燃費(確定値)+前回満タンからの走行距離。編集前に「この記録の意味」が分かる
2. 入力フォーム: S-02と同一構成(対象車両/日付/ODO/給油量/金額〔任意〕+自動単価/満タン/給油所/メモ)。全項目編集可
3. 「この記録を削除する」(赤テキストボタン)
4. 保存バー「変更を保存」(sticky)

**金額なし記録の表示**: 金額欄は空欄(プレースホルダ「—」)、単価の自動計算行は「単価 —(金額を入力すると自動計算)」と表示。算出サマリ(燃費・走行距離)は金額の有無に関係なく表示される

**操作・遷移**
- 変更を保存 → トースト「変更を保存しました(影響区間の燃費を再計算)」→ S-03
- 削除 → **確認ダイアログ**(記録の要約+「削除すると前後の区間の燃費が再計算されます」)→ 削除する(赤)/キャンセル → S-03
- バリデーションはS-02と同一

## S-07 燃費グラフ

## S-08 車両管理(一覧・登録・編集)

| 項目 | 内容 |
|---|---|
| 目的 | 複数車両の登録・編集・アーカイブ。**初回起動時はこの画面(登録フォーム)から開始** |
| ヘッダ | ←戻る(S-09)+タイトル。車両チップなし(車両横断画面) |

**レイアウト**
1. 車両リスト: **車両タイプアイコン(車/バイク・SVG線画)**+車両名+「選択中」バッジ / 補足(タイプ・メーカー・ODO・燃料種別)/ 右端に「編集」テキストボタン
   - **行タップ=選択中の車両に切り替え**(注記をリスト下に表示)
2. 「車両を追加」ボタン(ブルー二次ボタン)
3. 車両編集フォーム(追加/編集時に展開。実装時は別画面またはシートでも可):

| 項目 | 必須 | 備考 |
|---|---|---|
| 車両タイプ | ○ | **アイコン付きセグメントコントロール(車/バイク)で1タップ選択**。初期値: 車。切り替えるとメーカー候補が即時切り替わる(デザインガイド5.13) |
| 車両名 | ○ | 例: ノート |
| メーカー | - | **プルダウン選択+手入力可**(デザインガイド5.14)。候補は車両タイプに応じて切替: 車=トヨタ/ホンダ/日産/マツダ/スバル/三菱/スズキ/ダイハツ/レクサス/メルセデス・ベンツ/BMW/フォルクスワーゲン/アウディ/ボルボ、バイク=ホンダ/ヤマハ/スズキ/カワサキ/ハーレーダビッドソン/BMW/ドゥカティ/トライアンフ/KTM。末尾の「その他(手入力)」選択でテキスト入力欄を直下に表示 |
| 型式・グレード | - | テキスト(例: E13) |
| 初度登録年月 | - | `type="month"` |
| 登録時ODO | ○ | ヒント「燃費計算の起点になります」 |
| 燃料種別 | ○ | select(レギュラー/ハイオク/軽油)。初期値レギュラー |
| タンク容量 | - | ヒント「給油量の入力チェックに使われます」 |
| 車検満了日 | - | |

4. フォーム下: 保存(アンバー)/「この車両をアーカイブ(手放した)」(赤テキスト)

**操作・遷移**: 行タップ→選択切替+トースト / 編集→フォーム展開 / アーカイブ→確認のうえ一覧から非表示(記録は保持)

**バリデーション・挙動の補足**
- 車両タイプの切り替えでメーカー候補が変わった際、選択済みメーカーが新しい候補に無い場合は「選択してください」に戻す(車×ドゥカティ等の誤った組み合わせを残さない)
- ※データ項目への影響: Vehicle エンティティの `vehicleType`(列挙: car / motorcycle、必須、初期値 car)を使用(要件定義書 5.1 に定義済み)

## S-11 車両切り替えシート

| 項目 | 内容 |
|---|---|
| 目的 | 選択中の車両の切り替え。**2タップで完了** |
| 呼び出し元 | 各画面ヘッダの車両チップ / 入力画面(S-02/04/05)の「対象車両」行 |

**レイアウト(ボトムシート)**
- グラバーバー+見出し「車両を切り替え」
- 車両行(60px): **車両タイプアイコン(車/バイク・SVG線画)**+車両名+補足(メーカー・最新ODO)。**選択中の行はブルー文字+チェックマーク**。アーカイブ済みは非表示。タイプアイコンにより車とバイクがひと目で区別できる
- 最下部「+ 車両を追加」→ シートを閉じてS-08へ

**操作・遷移**
- 車両行タップ → 切り替え+シート自動クローズ+トースト「◯◯に切り替えました」
- タップ数: 車両チップ(1)→ 車両行(2)= **2タップで完了**(要件充足)
- 背景タップ/下スワイプで閉じる(切り替えなし)

**切り替え時の反映範囲**: ヘッダ車両名・**車両タイプアイコン** / ホームの全数値 / 履歴・グラフの表示データ / 入力画面の前回値ヒント・プレースホルダ。選択状態は端末に保存し次回起動時も維持(`selectedVehicleId`)

**モックのダミーデータ**: ノート(車)/ ジムニー(車)/ MT-07(バイク)の3台構成。MT-07 に切り替えるとヘッダ・入力画面のアイコンがバイクに変わり、燃費(24.8km/L)・前回ODO(18,240km)・タンク容量(14L)も切り替わる
