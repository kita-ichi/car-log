## 0. 共通仕様

### 0.1 画面構造

```
┌──────────────────────────┐
│ アプリバー(パネルネイビー)   │ ← 車両チップ or タイトル+戻る
│──────────────────────────│
│                          │
│  コンテンツ(スクロール)      │
│                          │
│  [保存バー(入力画面のみ)]    │ ← sticky。常に親指圏内
│──────────────────────────│
│ ホーム | 給油 | メンテ | 設定  │ ← タブバー(入力画面では非表示)
└──────────────────────────┘
```

- タブ対応: ホーム=S-01 / 給油=S-03(FABでS-02へ)/ メンテ=S-06(FABでS-05へ)/ 設定=S-09
- 入力・詳細画面(S-02/04/05)はタブバー非表示のモーダル扱い(誤タップ防止、キャンセルはヘッダ左の✕/戻る)
- 一覧・ホーム系画面(S-01/03/06/07)のヘッダには**車両チップ**(**車両タイプアイコン〔車/バイク〕**+選択中の車両名)を常時表示。タップでS-11を開く。アイコンは選択中の車両のタイプに追従する
- S-08(車両管理)・S-09(設定)は車両横断の画面のため車両チップなし(S-09には選択中車両名をテキスト表示)

### 0.4 車両写真の表示方針(共通)

車両に**写真1枚(任意)**を登録できる。表示仕様の詳細は**デザインガイド5.15**。画面横断のルールは次のとおり。

| 画面 | 写真あり | 写真なし(フォールバック) |
|---|---|---|
| S-01 ホーム ヒーロー | 写真を背景に敷き(**16:9**)、**スクリム(暗幕 .78)** を重ねる | **現行どおり無地ネイビー**(レイアウト変更なし) |
| S-08 車両一覧の行頭 | 44pxサムネイル+右下に車両タイプバッジ | 44px枠の中央に**車両タイプアイコン24px**(現行の見え方を枠内に配置) |
| S-11 切り替えシートの行頭 | 同上 | 同上 |
| ヘッダの車両チップ / 入力画面の対象車両行 | **写真は使わない**(現行のタイプアイコンのまま) | 同左 |

- **写真は任意・装飾**。未設定でも全画面が同じタップ数で使え、写真設定を促す割り込みは出さない
- **写真の有無でレイアウトを変えない**(リード領域は常に44px固定。行の高さ・車両名の開始位置は不変)
- ヘッダの車両チップに写真を入れないのは、20px相当では車種を判別できず、タイプアイコンの識別性(要件: 車・バイクをひと目で)を落とすため
- 設定・削除**・調整**の導線は **S-08 の車両編集フォームに一本化**する(ホームや切り替えシートに編集導線を増やさない=記録動線を汚さない)

**写真の調整(拡大縮小・位置)の共通ルール**(デザインガイド5.15.6)

- 車両ごとに **`zoom`(既定1.0=枠いっぱい)/ `focusX` `focusY`(既定0.5=中央)** の3値を持つ。既定値は**現行の `cover`+`center` と同じ表示**になる(=**すでに写真を設定済みのユーザーの見え方は変わらない**)
- 調整できるのは **S-08a 写真の調整**(S-08のフォームから開く)だけ。ホーム・一覧・切り替えシートからは調整できない
- **1つの調整値を比率の違う2つの枠に適用する**: 焦点(写真上の点)は全枠で共有、倍率はヒーロー枠(16:9)基準。**44pxサムネは `max(1, zoom)` にクランプ**して常に枠を埋める(小さな枠に余白を作らない)
- 縮小して余白が出た場合、**余白は無地ネイビー**(写真なしのヒーローと同じ色)で埋める

### 0.2 バリデーション表示の共通ルール

| レベル | 対象 | 表示方法 | 保存 |
|---|---|---|---|
| エラー(必須) | 必須項目の未入力 | 保存ボタンを無効化+ボタン下に「あと◯項目(必須はODO・給油量のみ。金額は任意)」 | 不可 |
| 警告 | ODO逆行 / タンク容量超過 / 燃費1〜60km/L範囲外 | 該当欄の直下にアンバーの警告チップをライブ表示 | **可**(要件6.1準拠) |

- 警告はダイアログにしない(入力の手を止めない)。入力のたびに即時再評価する
- 保存成功はトーストで通知し、**結果の燃費値を含める**(例: 「保存しました(燃費 19.2 km/L)」)

### 0.3 数値入力の共通仕様

| 項目 | inputmode | 補助表示 |
|---|---|---|
| ODO(km) | `numeric` | プレースホルダ+欄下ヒントに前回値 |
| 給油量(L) | `decimal`(小数2桁) | — |
| 金額(円)※任意 | `numeric` | **金額入力時のみ**欄下に「単価 ≒ ◯円/L(自動計算)」をライブ表示。未入力時は案内文「単価は金額を入力すると自動計算されます(前回 ◯円/L)」 |
| 費用(円) | `numeric` | 0円可 |

- 任意の数値項目(金額・費用)は、ラベル横にグレーの小さめテキスト「任意」を付ける(必須は赤の「*」)

## S-01 ホーム(ダッシュボード)

| 項目 | 内容 |
|---|---|
| 目的 | 現状把握(直近燃費)と、給油入力への最短導線 |
| ヘッダ | 車両チップ(左)+今日の日付(右) |

**レイアウト(上→下)**
1. **ヒーローパネル**(ネイビー・下角丸): 直近燃費を44pxのビッグナンバーで表示。下段に「平均燃費 / 前回比(▲緑・▼赤)/ 今月の燃料費」。**車両に写真があれば背景に敷く**(下記「車両写真をヒーローパネルに表示する」)
2. **CTA群**(画面中央=親指圏内):
   - 「給油を記録」: アンバーの特大ボタン(64px)→ S-02
   - 「メンテを記録」: ブルーの二次ボタン(56px)→ S-05
3. **燃費推移カード**: 直近12回のミニ折れ線(スパークライン)。カードタップ/「グラフを見る」→ S-07
4. **直近のメンテナンスカード**: 直近2〜3件(種別・日付・ODO・店舗・費用)。「すべて見る」/行タップ → S-06
5. (フェーズ2)リマインダー警告をヒーロー直下に挿入予定

**操作・遷移**: 車両チップ→S-11 / 給油を記録→S-02 / メンテを記録→S-05 / グラフ→S-07 / メンテ→S-06

**表示ルール**: 数値はすべて選択中の車両のもの。給油記録が無い場合、ビッグナンバーは「—」+「最初の給油を記録しましょう」を表示(初回はS-08の車両登録から開始)。**今月の燃料費は金額入力済みの給油記録のみを集計**する(金額なし記録は合計に含めない)

### 車両写真をヒーローパネルに表示する(デザインガイド5.15.3)

選択中の車両に写真があるとき、ヒーローパネルの**背景**に敷く。**燃費数値の可読性は写真の内容に一切左右させない**。

```
┌────────────────────────────────┐
│ アプリバー(無地ネイビー)             │ ← 写真は敷かない(車両チップの可読性を守る)
├────────────────────────────────┤
│▓▓▓▓ 愛車の写真(16:9・上側に抜け)▓▓▓▓│
│▓▓▓▓                        ▓▓▓▓│ ← 16:7から縦に約43px拡大(切れる量を減らす)
│▓▓ スクリム rgba(31,43,58,.78) 全面 ▓▓│ ← 可読性の担保はここ(均一に敷く)
│▓ 直近の燃費                      ▓│ ← 12px / --c-panel-sub-on-photo
│▓ 19.2 km/L                      ▓│ ← 44px 白 + text-shadow(保険)
│▓ 平均 18.6 ・ 前回比 +0.6 ・ ¥8,240 ▓│ ← 13px 補助色 / 15px白 / 前回比は on-photo 色
└──────────────────(下角丸24px)──┘
```

| 項目 | 仕様 |
|---|---|
| 画像 | ヒーロー全面・**既定は `cover`+`center`、調整値がある場合はデザインガイド5.15.6の描画規則** / 下角丸24pxでクリップ / `alt=""`(装飾) |
| スクリム | `--c-hero-scrim`(`rgba(31,43,58,.78)`)を**全面均一**に重ねる(縮小時の余白部分にも同じように敷く)。装飾のグラデーションを足す場合も**合成後 .78 未満の領域を作らない** |
| テキスト色 | 数値・強調は白のまま。**ラベル・補助文は `--c-panel-sub-on-photo`、前回比は `--c-trend-up/down-on-photo` に差し替える**(既存色のままでは 3.5〜3.8:1 に落ちる) |
| テキストシャドウ | `0 1px 2px rgba(11,18,26,.55)`。**あくまで保険**で、コントラスト比の担保はスクリム側で行う |
| 高さ | 写真ありは **`aspect-ratio: 16/9`**(375px幅で211px)。床として `min-height: 200px`。テキストが入りきらない場合のみ下に伸びる。テキストは下寄せにして上側に写真の抜けを作る |
| 縮小時の余白 | **無地ネイビー(`--c-panel`)で埋める**。写真の外周に `inset 0 0 0 1px rgba(255,255,255,.14)` の内枠(暗い写真が余白に溶けないため)。ぼかし背景は使わない |
| 写真なし | **現行の無地ネイビーのまま**(高さ・余白・文字色すべて変更なし) |
| 操作 | 写真はタップ不可(記録CTAの近くに操作を増やさない)。**ホームに写真の設定・調整導線は置かない**(→S-08) |

**ヒーロー比率を 16:7 → 16:9 に変更した理由**: 16:7 では横4:3のスマホ写真が**高さの58%しか映らず**、「一部しか表示されない」という声の主因になっていた。16:9 で 75% まで改善する。3:2・4:3 は 375×667 端末で燃費推移カードがフォールド外に出るため不採用(比較表はデザインガイド5.15.1)。

**「給油を記録」CTAの位置検証(375×667・上部セーフエリア20px・タブバー56px = フォールド611px)**

| | 16:7(旧) | **16:9(採用)** |
|---|---|---|
| 給油を記録(64px) | 260〜324 | **303〜367**(中心=画面高の50%) |
| メンテを記録(56px) | 336〜392 | **379〜435** |
| 燃費推移カード | 408〜524 | **451〜567** |

- **主要CTA・二次CTA・燃費推移カードはすべてフォールド内**に残る。CTAは中段の押しやすい位置(タブバーより上・画面中央)で、親指の可動域内
- 430×932 のような大型端末では、CTA中心が画面下端から 596px → **542px** と**むしろ親指に近づく**
- 写真あり(211px)/なし(≒128px)でヒーロー高が変わるため、車両切り替え時にCTAが最大83pxずれる(旧40px)。切り替えは S-11 経由の低頻度操作かつ直前のタップは画面下部のため許容する。**写真なしユーザーのレイアウトを変えない**ことを優先

**コントラスト検証(真っ白な写真=最悪ケース)**: 燃費44px 白 = **7.0:1** / ラベル・補助文13px = **4.8:1** / 前回比 ▲ = **4.7:1** ・▼ = **4.6:1**。写真の各画素は黒〜白の間にあるため、**どんな写真でもこの値を下回らない**(真っ黒な写真では 10.6〜16.1:1)。**縮小時の余白部分は #1F2B3A 相当で 14.2:1 / 10.5:1** と写真部分より安全なため、**この検証値は比率変更・調整機能の追加後も変わらない**。

**読み込み中・失敗時**: 未ロードの間は無地ネイビー(=写真なしと同じ)を表示し、到着したら150msでフェードイン。**スケルトンや点滅は出さない**(数値の読み取りを妨げるため)。読み込み失敗時も**無言で無地ネイビーにフォールバック**し、ホームにエラーを出さない。

## S-02 給油入力【最重要画面】

| 項目 | 内容 |
|---|---|
| 目的 | 給油直後の最速入力。**目標30秒・アプリ起動から保存まで10タップ以内**(数値入力を除く) |
| ヘッダ | ✕(キャンセル→前画面)+タイトル「給油を記録」。タブバー非表示 |

**レイアウト(入力順=画面上→下。頻度の高い項目ほど上、任意項目は下)**

| # | 項目 | 初期値・入力支援 |
|---|---|---|
| 1 | 対象車両 | 選択中の車両。行タップでS-11を開きその場で変更可(誤記録防止) |
| 2 | 給油日 | **今日**(`type="date"`) |
| 3 | ODO(必須) | プレースホルダ+ヒントに**前回ODO**。`inputmode="numeric"` |
| 4 | 給油量(必須) | `inputmode="decimal"`。単位L表示 |
| 5 | 支払金額・総額(**任意**) | `inputmode="numeric"`。ラベル横にグレーの「任意」表示。**金額入力時のみ単価を欄下にライブ自動計算表示**、未入力時は案内文+前回単価を表示。単価側からの入力はMVPでは詳細画面に譲り、本画面は総額のみ |
| 6 | 満タントグル | **初期値ON**。OFF時は「燃費は次の満タン給油時にまとめて計算されます」を表示 |
| 7 | 燃費プレビュー | 満タンON+**ODO・給油量入力済**で「この区間の燃費 ◯km/L・走行◯km」を保存前に表示(燃費はODOと給油量のみで計算するため**金額なしでも表示される**) |
| 8 | 給油所名(任意) | **前回値を初期表示**。欄の直下に**よく使う給油所のクイック選択チップ**(対象車両の記録から使用頻度順に最大3件。同数は直近に使った方を優先)を表示。タップで欄に入力、入力値と一致するチップは選択状態(デザインガイド5.10: ネイビー地白文字)、再タップで解除(欄をクリア)。候補が無い場合はチップ行ごと非表示。手入力も従来どおり可(S-04 も同様) |
| 9 | メモ(任意) | 空 |

**操作・遷移**
- 保存(sticky・アンバー56px)→ トースト「保存しました(燃費 19.2 km/L)」→ S-01へ戻る
- 部分給油の保存時はトースト「燃費は次の満タン給油で確定します」
- ✕ → 入力破棄して前画面へ(入力がある場合は破棄確認 ※実装時)

**タップ数の検証(標準フロー)**

| # | 操作 |
|---|---|
| 1 | (ホーム)「給油を記録」をタップ |
| 2 | ODO欄をタップ(テンキー入力) |
| 3 | 給油量欄をタップ(テンキー入力) |
| 4 | 金額欄をタップ(テンキー入力)※任意 |
| 5 | 「保存する」をタップ |

→ 金額まで入れて**5タップ**、**金額を入力しない場合は4タップ**(日付=今日、満タン=ON、給油所=前回値のためタップ不要)。要件の10タップ以内を満たす

**保存条件・バリデーション**
- **保存ボタンの活性条件: ODO・給油量の2項目が入力済み**(金額は不問)。揃うまで保存ボタン無効+「あと◯項目(必須はODO・給油量のみ。金額は任意)」表示
- ODO<前回ODO: ODO欄下に警告チップ(保存可)
- 給油量>タンク容量: 警告チップ(保存可)
- 算出燃費が1〜60km/L範囲外: 警告チップ(保存可)

**※データ項目への影響**: 金額の任意化は要件定義書(F-02・5.2 FuelRecord)に反映済み。`totalPrice` は null 許容(金額未入力時は `unitPrice` も null)

## S-03 給油履歴一覧

| 項目 | 内容 |

**レイアウト**: 日付降順のリスト。行構成:

| 位置 | 内容 |

**操作・遷移**: 行タップ→S-04 / FAB→S-02 / 「グラフ」→S-07 / 車両チップ→S-11

## S-04 給油詳細・編集

| 項目 | 内容 |
|---|---|
| 目的 | 記録の確認・修正・削除 |
| ヘッダ | ←戻る(S-03)+タイトル。タブバー非表示 |

**レイアウト(上→下)**
1. **算出サマリカード**(緑背景): 燃費(確定値)+前回満タンからの走行距離。編集前に「この記録の意味」が分かる
2. 入力フォーム: S-02と同一構成(対象車両/日付/ODO/給油量/金額〔任意〕+自動単価/満タン/給油所/メモ)。全項目編集可
3. 「この記録を削除する」(赤テキストボタン)
4. 保存バー「変更を保存」(sticky)

**金額なし記録の表示**: 金額欄は空欄(プレースホルダ「—」)、単価の自動計算行は「単価 —(金額を入力すると自動計算)」と表示。算出サマリ(燃費・走行距離)は金額の有無に関係なく表示される

**操作・遷移**
- 変更を保存 → トースト「変更を保存しました(影響区間の燃費を再計算)」→ S-03
- 削除 → **確認ダイアログ**(記録の要約+「削除すると前後の区間の燃費が再計算されます」)→ 削除する(赤)/キャンセル → S-03

### 車両写真の設定(デザインガイド5.15.4)

**置き場所**: フォームの **車両名の直下**(必須2項目のすぐ後、任意項目群の先頭)。ラベルは「車両の写真」+ 横にグレーの「任意」(§0.3 の任意項目の表記に準拠)。
理由 — 「タイプ・名前・写真」で"この車両が何か"の塊としてまとまり、必須入力を先に片付けられる。フォーム先頭に置くと新規登録時に**写真が必須のように見える**ため避ける。

```
[未設定]                              [設定済み]
車両の写真  任意                        車両の写真  任意
┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐      ┌───────────────────────┐
                                     │▓ 写真+スクリム(ホーム相当)▓│
       ⬚  写真を選ぶ           　      │▓ 調整値を反映した見え方     ▓│
                                     │▓ 直近の燃費 19.2 km/L    ▓│
└ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘      └───────────────────────┘
撮影・アルバムのどちらからでも選べます        ホームでの見え方
                                     ┌──┐
                                     │▣◍│ 一覧・切り替えでの見え方
                                     └──┘
                                     [ ⤢ 位置とサイズを調整 ]  ← 幅いっぱい
                                     [ 写真を変更 ]   写真を削除
```

**状態ごとの見た目・操作**

| 状態 | 表示 | 操作(タップ数) |
|---|---|---|
| **未設定** | 16:9 の破線枠(角丸12px・薄グレー地)。中央に写真アイコン+**「写真を選ぶ」**。欄下ヒント「**撮影・アルバムのどちらからでも選べます**」(新規登録時は「あとから設定できます」を併記) | **枠全体がタップ領域**。1タップでOS標準の選択シート |
| **処理中** | 枠内にスピナー+「写真を準備しています…」。ボタンと保存ボタンを無効化 | 操作不可。150ms未満で終わるときはスピナーを出さない(ちらつき防止) |
| **設定済み** | ① **ヒーロープレビュー**(16:9・**実際のスクリムを適用**・**調整値を反映**・キャプション「ホームでの見え方」)/ ② **サムネプレビュー行**(44px+タイプバッジ+「一覧・切り替えでの見え方」) | ①「**位置とサイズを調整**」(幅いっぱい・ブルー二次・48px)→ **S-08a** / ②「**写真を変更**」(ブルー二次)+「**写真を削除**」(赤テキスト)を横並び |
| **エラー** | 枠をアンバー地(`--c-warn-bg`)にし「この写真は読み込めませんでした。別の写真を選んでください」+「写真を選ぶ」 | 選び直しのみ。**ダイアログは出さない**(§0.2 手を止めない) |

- **文言はカメラ限定に読めない表現にする**: 「写真を選ぶ」/「写真を変更」(×「撮影する」)。実装は `<input type="file" accept="image/*">` のみとし、**`capture` 属性は付けない**(カメラ固定になる端末があるため)
- **スクリム適用済みのプレビュー**を出すことが要点。ホームでは暗く表示されることを事前に伝え、「思っていたのと違う」を防ぐ
- プレビュー自体は**タップ不可**のまま(「ホームでの見え方」の窓に操作を載せない)。調整はボタンから入る
- **調整の存在を伝える一度きりのヒント**: 既定(枠いっぱい)で**写真の70%未満しか映らない**場合(縦写真・パノラマ)のみ、プレビュー直下にグレーのヒントチップ「**縦長の写真のため、一部だけが表示されます**」+「調整する」を出す。**チップ全体がタップ領域**。アンバー(警告色)は使わない(不具合ではなく仕様のため)
- 追加・変更・削除**・調整**は**他項目と同様「保存する」で確定**(即時反映しない)。キャンセルすれば元に戻る
- **写真を差し替えたら調整値は既定(枠いっぱい・中央)に戻す**。前の写真の調整を新しい構図に引き継がない
- **削除は確認ダイアログ**(デザインガイド5.11 の流儀: キャンセル左・削除右・赤)
  - タイトル「写真を削除しますか?」/ 本文「**保存すると反映されます。給油・メンテの記録は削除されません**」/ 確認ラベル「削除」
  - 削除後はプレースホルダ(未設定)に戻り、ホーム・一覧の表示はタイプアイコン/無地ネイビーに戻る。**調整値も破棄する**
- 保存失敗(端末の空き容量不足など)はトースト「写真を保存できませんでした(端末の空き容量をご確認ください)」。**入力中の他項目は保持**する
- アーカイブした車両の写真は保持する。**アーカイブ済み一覧の行頭も同じサムネイル仕様**(復元前にどの車両かを見分けられる)

### S-08a 写真の調整(拡大縮小・位置)【全画面シート】

| 項目 | 内容 |
|---|---|
| 目的 | **「設定した画像の一部しか表示されない」の解消**。枠に対する写真の**大きさと位置**をユーザーが決められるようにする |
| 呼び出し元 | S-08 車両編集フォームの写真ピッカー「位置とサイズを調整」/ ヒントチップ |
| ヘッダ | ✕(破棄)+ タイトル「写真の調整」。**タブバー非表示**(モーダル扱い) |
| 仕様の詳細 | デザインガイド **5.15.6(値の定義と描画規則)/ 5.15.7(シートの見た目・操作)** |

**表示項目(上→下)**

1. **編集枠(16:9・実寸相当)**: 素の写真(**スクリムなし**)+三分割グリッド。枠外は暗い作業面でマスク。枠下部に「直近の燃費 19.2 km/L」の**ゴースト表示**(文字が乗る位置を避けて構図を決めるため)
2. 注記: 「ドラッグで位置・スライダーで大きさ」/「**ホームでは全体に暗幕がかかります(数値を読みやすくするため)**」
3. **倍率スライダー**(両端に −/+ 44pxボタン・現在値を%表示)。ノッチ2か所(**全体** / **枠いっぱい**)。100%(枠いっぱい)にスナップ
4. **プリセット2つ**: 「**全体を表示**」/「**枠いっぱいに戻す**」(=既定値へのリセット)。**どちらも位置を中央に戻す**
5. **44pxサムネプレビュー**(「一覧・切り替えでの見え方」)— リアルタイム更新
6. **完了**(アンバー56px・下部固定)+ 注記「調整はフォームの「保存する」で確定します」

**操作**

| 操作 | 挙動 |
|---|---|
| 1本指ドラッグ | 位置を移動(**はみ出している軸のみ**。枠に収まっている軸は中央固定で動かない) |
| スライダー / −+ボタン | 拡大縮小(下限=写真全体が収まる倍率、上限=3.0) |
| ピンチ | 拡大縮小(**補助**。片手操作を妨げないよう、これに依存する設計にはしない) |
| 全体を表示 | 1タップで写真全体を枠内に収める(**ユーザーの主訴への最短経路**) |
| 枠いっぱいに戻す | 1タップで既定値(cover・中央)に戻す |
| 完了 | 調整をフォームに反映して閉じる(DB保存はフォームの「保存する」) |
| ✕ | 変更なし=即閉じる / 変更あり=確認ダイアログ「調整を破棄しますか?」(キャンセル左・破棄右・赤) |

**タップ数**: 写真設定後、「位置とサイズを調整」(1)→「全体を表示」(2)→「完了」(3)→ フォームの「保存する」(4)。**主訴の解決まで4タップ**、細かい調整をしたい場合のみドラッグ+スライダーを使う。

**縮小したときの余白**: 無地ネイビーで埋める(ホームと同じ)。**スクリムは余白の上にも均一に敷く**ため、燃費数値のコントラストはむしろ写真部分より高くなる(検証は S-01)。

**アクセシビリティ**: スライダーは `<input type="range">`+`aria-valuetext`(「120%」「全体」)。ドラッグの代替として**矢印キーで焦点を1%ずつ移動**(Shiftで10%)。位置調整ができない環境でも「全体を表示」だけで主目的は達成できる。

**※データ項目への影響**:
- Vehicle に写真(任意・1枚)の保持が必要。表示側の要件は「**長辺1280px程度・EXIFの回転を反映した向き**」(ヒーロー最大 430px幅×3dpr 相当)。保持形式・リサイズ処理は実装側で決定する
- **調整値**(任意・写真1枚につき1組)を追加する。**画像そのものは加工しない**(トリミング画像を作らない=やり直せる・再圧縮で劣化しない)

| 値 | 型・範囲 | 既定値 | 定義 |
|---|---|---|---|
| `zoom` | number(小数2桁)/ 下限=全体が収まる倍率・上限3.0 | **1.0** | **ヒーロー枠(16:9)を隙間なく埋める倍率を1.0とした相対倍率**。1未満=縮小(余白)/1超=拡大 |
| `focusX` | number(小数3桁)/ 0〜1 | **0.5** | 枠に写したい**写真上の点**の横位置(0=左端・1=右端) |
| `focusY` | number(小数3桁)/ 0〜1 | **0.5** | 同・縦位置(0=上端・1=下端) |

- 値が**未設定(undefined)= 既定値**として扱う。既定値の描画結果は現行の `cover`+`center` と完全に一致するため、**既存ユーザーのデータ移行は不要・見え方も変わらない**
- 範囲外の値は**読み込み時にクランプ**して描画する(壊れた値で表示を崩さない)
- JSONバックアップ(S-09)には Vehicle の一項目として含める(写真本体を含めない設定でも調整値は出力してよい。写真がなければ無害)

**レイアウト(ボトムシート)**
- グラバーバー+見出し「車両を切り替え」
- 車両行(60px): **行頭に車両写真サムネイル(44px)、写真なしは車両タイプアイコン(車/バイク・SVG線画)**+車両名+補足(メーカー・最新ODO)。**選択中の行はブルー文字+チェックマーク**。アーカイブ済みは非表示
- 最下部「+ 車両を追加」→ シートを閉じてS-08へ

**車両写真の扱い(2タップの速度を落とさないこと)**

| 論点 | 仕様 |
|---|---|
| サイズ | 44px・角丸8px・1:1 cover。行高は**現行の60px を維持**(44+8×2)。文字サイズ・タップ領域は変更しない |
| 調整値の反映 | 焦点(`focusX/focusY`)は反映し、倍率は `max(1, zoom)` にクランプ(§0.4)。**44px枠は常に写真で埋め、余白は作らない** |
| 車/バイクの識別 | 写真ありの行は**右下に車両タイプバッジ(18px)**を重ねる。シートの補足行にはタイプ名が出ないため、**バッジで識別性を担保する**(要件: 車・バイクをひと目で) |
| 写真なし | 44px枠の中央にタイプアイコン24px。**写真あり/なしで車両名の開始位置がズレない** |
| 表示タイミング | **画像の取得を待ってシートを開かない**。シートは常に即時表示し、写真は後から枠内にフェードイン。`loading="eager"` / `decoding="async"` |
| レイアウトシフト | 枠サイズが固定のため、写真が後から入っても**行が動かない**(狙った行を押し外さない) |
| 失敗時 | 無言でタイプアイコンにフォールバック(シート内にエラーを出さない) |
| 編集導線 | シートには写真の設定導線を**置かない**(切り替え専用に保つ。設定はS-08) |

**操作・遷移**
- 車両行タップ → 切り替え+シート自動クローズ+トースト「◯◯に切り替えました」
- タップ数: 車両チップ(1)→ 車両行(2)= **2タップで完了**(要件充足)
- 背景タップ/下スワイプで閉じる(切り替えなし)

**切り替え時の反映範囲**: ヘッダ車両名・**車両タイプアイコン** / **ホームのヒーロー写真(未設定の車両に切り替えたら無地ネイビーに戻る)** / ホームの全数値 / 履歴・グラフの表示データ / 入力画面の前回値ヒント・プレースホルダ。選択状態は端末に保存し次回起動時も維持(`selectedVehicleId`)

**モックのダミーデータ**: ノート(車)/ ジムニー(車)/ MT-07(バイク)の3台構成。MT-07 に切り替えるとヘッダ・入力画面のアイコンがバイクに変わり、燃費(24.8km/L)・前回ODO(18,240km)・タンク容量(14L)も切り替わる
