## 3. 層の責務

| 層 | 責務 | してはいけないこと |
|---|---|---|
| `types/` | エンティティの型定義のみ | ロジックを持たない |
| `logic/` | 燃費計算・統計・バリデーション(**純粋関数**) | UI・DB(Dexie)への依存 |
| `db/repositories/` | CRUD、燃費キャッシュの整合性維持、金額の正規化 | 画面固有の整形(表示用フォーマットはUI側) |
| UI(未実装) | 画面・状態管理。リポジトリと logic を呼ぶだけ | 燃費計算や検証ルールの重複実装 |

### 設計上の重要ポイント

1. **燃費キャッシュ(`FuelRecord.fuelEconomy`)はリポジトリ層が自動維持する。**
   `fuelRecordRepository` の create / update / remove を使う限り、
   追加・編集・削除・満タンフラグ変更時の影響区間の再計算は自動で行われる。
   **UI側で燃費を計算して保存する必要はない(してはいけない)。**
2. **金額(総額・単価)の正規化もリポジトリ層が行う。**
   総額を渡せば単価を自動算出、単価を渡せば総額を逆算、両方省略なら両方 null。
3. **日付は文字列で統一**: 日付 `'YYYY-MM-DD'`、年月 `'YYYY-MM'`、日時 ISO 8601。
   文字列比較 = 時系列比較が成立する。Date オブジェクトはDBに入れない。
4. **車両の削除は無い。** `archive()` で非表示(記録は保持)。一覧は `listActive()` を使う。

## 4. DBスキーマとマイグレーション

`app/src/db/database.ts` の `AppDatabase`。DB名 `car-maintenance-db`。

```
v1 (2026-07-03):
  vehicles:            id

  maintenanceRecords:  id, vehicleId, [vehicleId+date], [vehicleId+type]
```

**スキーマ変更の手順**: 既存の `version(1)` は消さず、`this.version(2).stores({...}).upgrade(tx => {...})` を**追記**する(Dexie が差分マイグレーションを実行)。変更したら本メモの履歴も更新すること。

## 5. frontend-developer 向け API一覧

### 5.1 リポジトリ(`app/src/db/repositories/index.ts` から import)

すべて `Promise` を返す。シングルトン(`vehicleRepository` 等)をそのまま使う。

**vehicleRepository**
| API | 用途(画面) |
|---|---|
| `create(input: VehicleInput)` | 車両登録(S-08)。vehicleType 省略時 car、fuelType 省略時 regular |
| `getById(id)` / `listActive()` / `listAll()` | 一覧はアーカイブ除外の `listActive()`(S-08/S-11) |
| `update(id, patch)` | 車両編集(S-08) |
| `archive(id)` / `unarchive(id)` | 手放した車両の非表示・復元(記録は保持) |

**fuelRecordRepository**
| API | 用途(画面) |
|---|---|
| `create(input: FuelRecordInput)` | 給油保存(S-02)。isFullTank 省略時 true。**保存後の戻り値に算出燃費が入っている**(トースト表示に使える) |
| `getById(id)` | 給油詳細(S-04) |
| `listByVehicle(vehicleId, order?)` | 履歴一覧(S-03)。既定は日付降順。グラフは `'asc'` |
| `latestByVehicle(vehicleId)` | 前回ODO・前回給油所名・前回単価のヒント表示(S-02) |
| `update(id, patch)` / `remove(id)` | 編集・削除(S-04)。**影響区間の燃費は自動再計算される** |

**maintenanceRepository**
| API | 用途(画面) |
|---|---|
| `create(input)` / `getById(id)` / `update(id, patch)` / `remove(id)` | メンテ記録(S-05/S-06) |
| `listByVehicle(vehicleId, type?)` | 履歴一覧(S-06)。type 指定で種別フィルタ。日付降順 |
| `latestByType(vehicleId, type)` | 「前回オイル交換いつ?」/ リマインダー判定の基点 |

**settingsRepository**
| API | 用途 |
|---|---|
| `getSelectedVehicleId()` / `setSelectedVehicleId(id \| null)` | 選択中車両の保存・復元(S-11。起動時に復元) |
| `getAppSettings()` | 設定一式の取得 |

### 5.2 純粋関数(`app/src/logic/fuelEconomy.ts` / `validation.ts`)

**fuelEconomy.ts**
| 関数 | 用途(画面) |
|---|---|
| `calculateFuelEconomies(records)` | 満タン法の一括計算(通常はリポジトリ経由で不要) |
| `previewFuelEconomy(existingRecords, {odo, fuelAmount, isFullTank})` | 保存前の燃費プレビュー(S-02 の「この区間の燃費◯km/L・走行◯km」)。金額不要 |
| `calculateFuelStats(records)` | 平均(総距離÷総給油量)・ベスト・ワースト(S-01/S-07)。records は `listByVehicle(id, 'asc')` の結果でよい |
| `calculateMonthlyFuelCost(records, year, month)` | 今月の燃料費(S-01)。**金額入力済みのみ合計**、`excludedCount` で「対象外◯件」を注記表示 |
| `computeUnitPrice(total, amount)` / `computeTotalPrice(unit, amount)` | 単価⇔総額のライブ表示(S-02 欄下) |

**validation.ts**
| 関数 | 用途(画面) |
|---|---|
| `validateFuelRecord(input, context)` | S-02/S-04。context に `previousOdo`(latestByVehicle から)・`tankCapacity`(車両から)・`existingRecords` を渡す |
| `validateMaintenanceRecord(input, context)` | S-05 |

戻り値 `ValidationResult`:
- `errors`(保存不可 → 保存ボタン無効化)/ `warnings`(アンバーチップ表示のみ、**保存はブロックしない**)
- `canSave`: エラーが無ければ true(警告があっても true)
- 各 issue は `{ level, code, field, message }`。`field` で警告チップを出す欄を特定、`message` は日本語表示文そのまま使用可

### 5.3 使用例(S-02 給油入力の保存フロー)

```ts
import { fuelRecordRepository, vehicleRepository } from './db/repositories'
import { previewFuelEconomy } from './logic/fuelEconomy'
import { validateFuelRecord } from './logic/validation'

// ライブバリデーション(入力のたび)
const existing = await fuelRecordRepository.listByVehicle(vehicleId, 'asc')
const latest = existing[existing.length - 1]
const vehicle = await vehicleRepository.getById(vehicleId)
const result = validateFuelRecord(
  { date, odo, fuelAmount, totalPrice, isFullTank },
  { previousOdo: latest?.odo ?? null, tankCapacity: vehicle?.tankCapacity ?? null, existingRecords: existing },
)

// 保存(燃費の再計算は自動)
if (result.canSave) {
  const saved = await fuelRecordRepository.create({ vehicleId, date, odo, fuelAmount, totalPrice, isFullTank, stationName, memo })
  // saved.fuelEconomy → トースト「保存しました(燃費 ◯km/L)」/ null なら「次の満タン給油で確定します」
}
```
